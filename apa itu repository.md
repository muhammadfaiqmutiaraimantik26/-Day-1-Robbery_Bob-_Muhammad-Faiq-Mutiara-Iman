apa itu repository? Repository (sering disingkat repo) adalah tempat
untuk menyimpan, mengelola, dan mengorganisasi file atau data suatu
proyek.

Ada beberapa tujuan utama repository: Penyimpanan : Menyimpan semua file
proyek di satu tempat. Pengorganisasian : Membuat file lebih terstruktur
dan mudah ditemukan. Kolaborasi : Memudahkan beberapa orang bekerja
dalam satu proyek. Dokumentasi : Menyimpan catatan perkembangan proyek.
Riwayat perubahan : Melihat perubahan yang pernah dilakukan dan siapa
yang melakukannya. Backup : Membantu menjaga salinan proyek agar tidak
hanya tersimpan di satu perangkat.
